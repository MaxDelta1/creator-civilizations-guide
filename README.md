# Creator Civilizations — Guide

Online copy of the guide that ships inside the Minecraft mod Creator Civilizations (`/guide` in game).

Download the mod: https://www.curseforge.com/minecraft/mc-mods/creator-civilizations

## Voice pack

The [Releases](https://github.com/MaxDelta1/creator-civilizations-guide/releases) of this repository hold the server-side voice assets (pre-rendered voice pack and the creators' own speech models). The mod downloads them itself once the server operator agrees — checksums verified — so there is no need to download them by hand.
